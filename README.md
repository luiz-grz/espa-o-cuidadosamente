🧠 Espaço CuidadosaMente — Site Institucional

Site institucional do **Espaço CuidadosaMente**, uma clínica multidisciplinar de saúde mental localizada em Niterói (RJ). O projeto foi desenvolvido com HTML, CSS e JavaScript puro, com foco em design elegante, acessível e responsivo.

🌐 Sobre o Projeto

O Espaço CuidadosaMente oferece cuidado integral para toda a família, reunindo diferentes especialidades da saúde mental e do desenvolvimento humano em um só lugar. Este repositório contém o código-fonte do site institucional da clínica.

O site apresenta:
- Apresentação da clínica e sua proposta de cuidado integral
- Listagem dos serviços e especialidades oferecidos
- Galeria de fotos do espaço
- Formulário de agendamento de consulta
- Depoimentos de pacientes
- Informações de contato, redes sociais e mapa de localização

🛠️ Tecnologias Utilizadas

- HTML5 — estrutura das páginas
- CSS3 — estilização completa com variáveis, animações e responsividade
- JavaScript — interatividade (menu mobile, formulário de agendamento, galeria)
- Google Fonts — tipografia (Playfair Display e DM Sans)
- Font Awesome — ícones
